# rozword - the word processor
A word processor like MS Word, for rozOS (phase 26a; tables, pictures,
header and footer in 1.1, Word .docx in 1.2). Install it with
  `rozpkg install rozword`
then Start > Office > rozword, or `rozword` in the terminal, or double-
click a .rwd file in [[filemanager|Files]].

== The window ==
White A4 pages with 1 inch margins; text flows onto the next page by
itself. Menu (F10), toolbar, and at the bottom: page, word count, zoom,
Bangla/English.

== Formatting ==
  Toolbar     font, size, style (Normal, Title, Heading 1-3), B I U S,
              color, alignment (left, center, right, justify),
              bullets, numbering
  Ctrl+B/I/U  bold, italic, underline
  Ctrl+L/E/R/J  left, center, right, justify
  Ctrl+0..3   Normal, Heading 1, 2, 3
  Ctrl+> Ctrl+<  bigger / smaller text
  Format > Line spacing 1.0 / 1.15 / 1.5 / 2.0
  Insert > Page break, Date and time
Select text first to change it; without a selection the change is for
what you type next. Enter on an empty bullet ends the list.

== Tables ==
  Insert > Table...   columns x rows, e.g. `3 x 2`
  Tab / Shift+Tab     next / previous cell; Tab in the last cell adds a row
  Table menu          add a row below, a column to the right, delete a
                      row / column / the whole table, wider / narrower
                      column
A cell can hold several paragraphs, lists and pictures; rows that do not
fit on the page move to the next page.

== Pictures ==
  Insert > Picture...   PNG, JPEG, GIF, BMP, TGA, PPM - placed centered,
                        as wide as the text at most
  Format > Picture size...   width in % of the text width
  click it, then Backspace / Delete   remove it
The picture itself is kept inside the .rwd file.

== Header and footer ==
  Insert > Header... / Footer...   text at the top / bottom of every page,
                                   left, center or right
  {page} and {pages}               the page number and the number of pages
  Insert > Page numbers            footer "Page 1 of 3" at once

== Bangla ==
Ctrl+Space switches to Bangla (Avro phonetic, see [[bangla]]):
"ami bangla likhi" -> আমি বাংলা লিখি. Conjuncts (ক্ষ, ন্ধ্য ...) are joined
by the shaping engine. Any font can be used; Bangla letters come from
Noto Sans Bengali, or pick Hind Siliguri / Noto Serif Bengali / Tiro
Bangla as the font.

== Editing ==
  Ctrl+Z / Ctrl+Y   undo / redo        Ctrl+X/C/V  cut, copy, paste
  Ctrl+A            select all         Ctrl+F, F3, Ctrl+H  find, next, replace
  Ctrl+arrows       word by word       Shift + keys/click  select
  double-click      select a word      right-click  menu
  Ctrl+wheel, Ctrl+= / Ctrl+-   zoom
Copy and paste between rozword windows keeps the formatting; to other
programs it pastes plain text.

== Files ==
  .rwd   rozword's own format (keeps everything; plain UTF-8 text inside)
  .docx  Word documents (1.2, phase 26b-3): File > Open opens them,
         File > Save as Word (.docx) writes one; Ctrl+S on an opened
         .docx saves it as .docx again. Kept: text, fonts, sizes, bold,
         italic, underline, strike, colours, alignment, Title/Heading 1-3,
         bullets and numbering, line spacing, page breaks, tables,
         pictures, header and footer with page numbers. Things rozword
         does not know (text boxes, comments, footnotes, shapes, tracked
         changes) are left out when it opens the file.
  .txt   open any text file; File > Export as text writes one
Save: Ctrl+S, Save as: F12. A sample: /usr/share/doc/rozword/welcome.rwd
Without a window: `rozword -c IN OUT` converts between .rwd, .docx and
.txt (for example `rozword -c report.docx report.rwd`).
Saving as PDF comes in the next version.

== Build it yourself ==
The source is in /usr/src/rozword:
  `cd /usr/src/rozword && make`          with TCC (under a second)
  `make CC=gcc`                          with GCC ([[gcc]])
  `make install`                         copy to /usr/bin
See [[rozpkg]], [[c-programming]].
