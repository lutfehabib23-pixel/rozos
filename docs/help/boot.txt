# From power-on to the prompt
1. Firmware (BIOS or UEFI) starts Limine from the disk (or the CD
   image with `make run-iso`).
2. Limine shows the menu ([[boot-menu]]: installed kernels, factory,
   no init), loads the kernel and the initrd, sets up 64-bit mode
   and the framebuffer.
3. Phase 24a (quiet boot): the screen shows one line,
   "Starting rozOS <version> ........ ok" - one dot for every part
   that started. Warnings still appear in full. Everything is still
   written to the serial port, and kmon `bootlog` shows it all again.
   Add `bootdebug` to the kernel command line ([[boot-menu]]) to see
   the full output below on the screen, as before.
   The kernel prints [ OK ] lines as it starts each part: serial,
   screen, GDT/IDT, timer, keyboard, memory, ACPI/APIC, scheduler,
   syscalls, PCI, AHCI, partitions, ext2 on /, FAT on /boot,
   tmpfs on /tmp, devfs on /dev. The first line has the build number.
4. It gives the bootloader's memory back and prints /etc/motd.
5. It starts /bin/init as pid 1 ([[init]]), which starts [[rozsh]].
If something fails you see a red KERNEL PANIC with registers; the
serial terminal on the PC keeps a copy. See [[kernel]] and [[qemu]].
