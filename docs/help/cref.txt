# cref, crefview - the C (and C++) reference (phase 19a, 19b, 19c, 17c)
Every function of the C library with its syntax, what it does, what it
returns, and a small program that uses it - like the help of Turbo C.
Also the C language itself: types, if/for/while, pointers, structs,
printf and scanf codes, operators, the preprocessor ...

== In Code (the editor) ==
  Ctrl+F1     help for the word under the cursor (printf, strcpy, for ...)
  Shift+F1    the reference with its index
  Help menu   the same two
== In edit (terminal editor) ==
  Ctrl+F1     the page for the word under the cursor
  Shift+F1    type a name
  in the page: Up/Down/PgUp/PgDn scroll, C copies the example (then Esc
  and Ctrl+V pastes it into your file), Esc goes back
== The window: crefview ==
  `crefview`          index (Start > Development > C reference)
  `crefview strtol`   one page
  Find: type part of a name or a word (Enter opens the first match).
  Click a name under "See also" to follow it; Back returns.
  Copy example   puts the program on the clipboard (Ctrl+V in Code/edit)
  Try it         opens the example in Code - press F5 to compile and run
== In a terminal: cref ==
  `cref printf`        the page
  `cref -k string`     everything that mentions "string"
  `cref -l`            the headers;  `cref -l math.h`  all of one header
  `cref -x qsort > q.c; tcc q.c -o q; ./q`    take an example and run it
  `cref -s fopen`      only the syntax

== C++ (phase 17c) ==
21 pages under [ C++ language ] and the C++ headers: cpp-hello, class,
virtual, template, namespace, references, lambda, range-for, try, new,
operator-overloading, std::cout, std::string, std::vector, std::map,
std::sort, std::unique_ptr, std::ifstream, std::stringstream, std::thread,
std::chrono. `cref vector` works too. Try it opens the example as a .cpp
file - Code builds it with g++ ([[gcc]]).

== What is covered ==
Phase 19a: the C language, <stdio.h>, <stdlib.h>, <string.h>,
<strings.h>, <ctype.h>, <math.h>, <time.h> - every function.
Phase 19b: POSIX - every function of
  files       <unistd.h> <fcntl.h> <sys/stat.h> <dirent.h> <sys/mman.h>
              <sys/uio.h> <sys/ioctl.h> <sys/file.h> <utime.h>
  processes   fork/exec/wait, <signal.h> <setjmp.h> <sys/time.h> <poll.h>
              <sys/select.h> <sys/resource.h> <sys/times.h> <sys/utsname.h>
              <sys/random.h> <sys/mount.h> <sys/reboot.h>
  threads     <pthread.h> <semaphore.h> <sched.h>
  network     <sys/socket.h> <netinet/in.h> <arpa/inet.h> <netdb.h>
  text        <termios.h> <pty.h> <getopt.h> <regex.h> <fnmatch.h>
              <glob.h> <libgen.h> <wchar.h> <wctype.h> <locale.h>
              <langinfo.h> <iconv.h>
  other       <pwd.h> <grp.h> <syslog.h> <err.h> <dlfcn.h> <search.h>
              <fenv.h> <inttypes.h>
Pages also say what rozOS does differently (one user, no symbolic
links, no shared libraries ...). Try `cref -l` for the full list.
Phase 19c: the rozOS libraries - every function of
  <rozgfx.h>   graphics: shapes, pictures, text, keys and mouse
  <rozui.h>    windows: buttons, text boxes, lists, menus, dialogs
  <rozgame.h>  games: loop, input, images, sprites, maps, camera, particles
  <rozhttp.h>  http/https downloads; <rozos.h> rozOS system calls;
  <rozcref.h>  this reference itself
and short guides: the Lua `game` module (luagame - Try it runs the script),
the Lua C API (<lua.h>) and zlib (<zlib.h>).
Libraries: Code (F5) and edit (Ctrl+R) link -lrozui -lrozgame -lrozgfx -lm
always, and add -lrozhttp -lbearssl, -llua, -lz or -lrozcref when the
program includes that header - so every example runs with Try it.

The pages are text files in /usr/share/cref (source: docs/cref in the
rozOS tree). Every example is compiled and run when rozOS is built
(`make cref-check`), so they all work. See [[c-programming]], [[tcc]],
[[code]], [[edit]].
