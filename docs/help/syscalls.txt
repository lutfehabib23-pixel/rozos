# System calls
A program asks the kernel for something with the `syscall` instruction:
number in rax, arguments in rdi rsi rdx r10 r8 r9, result in rax (a
negative number is -errno). `int 0x80` works the same way as a backup.
rozOS uses the Linux x86-64 numbers, for example:
  0 read    1 write    2 open     3 close    4 stat    5 fstat
  8 lseek   9 mmap    11 munmap  12 brk     16 ioctl  20 writev
 32 dup    33 dup2    35 nanosleep 39 getpid 57 fork  59 execve
 60 exit   61 wait4   62 kill    63 uname   79 getcwd 80 chdir
 83 mkdir  84 rmdir   87 unlink 217 getdents64  228 clock_gettime
 41 socket 42 connect 43 accept 44 sendto 45 recvfrom 48 shutdown
 49 bind   50 listen  54 setsockopt 55 getsockopt   ([[sockets]])
500 rozos_kmon (rozOS only: starts [[kmon]])
169 reboot ([[reboot]])   318 getrandom ([[random]])
501 rozos_netinfo, 502 rozos_netconfig ([[ifconfig]])
phase 13:   7 poll   22 pipe   293 pipe2   77 ftruncate ([[pipes]])
503 rozos_shm_open, 504 rozos_shm_unlink ([[shm]])
phase 14:  13 rt_sigaction (SIG_IGN only)  109 setpgid  111 getpgrp
112 setsid  121 getpgid  124 getsid  505 rozos_openpty ([[pty]]);
socket(AF_UNIX) through the normal socket calls ([[pty]])
[[rozlibc]] wraps these in normal C functions (write(), fork() ...).
The kernel checks every pointer a program passes before using it.
