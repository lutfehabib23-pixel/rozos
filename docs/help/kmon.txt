# kmon - the kernel monitor
kmon is a small command line built into the kernel, for looking at the
machine from the inside. Start it from the shell with `kmon`; `exit`
returns to the shell. (It also takes over the console if [[init]] dies.)
kmon runs as a kernel thread; programs keep running meanwhile.

== Useful commands ==
  `help`            list everything
  `ps`              processes and kernel threads, CPU time, states
  `kill <pid> [s]`  end a process (default signal 9)
  `run p args`      start a program and wait; `spawn p args` in background
  `mem`, `heap`     memory map and kernel heap
  `lspci`, `disks` (partitions + file system details), `df`, `mount`, `sync`, `net`
  `ls`, `cat`, `stat`, `tree`, `write`, `fill`, `cp`  (kernel file access)
  `irq`, `apic`, `acpi`, `ticks`, `date`, `keys`, `mouse`
  `reboot`, `halt`
kmon has its own current directory and does not see shell variables.
See [[processes]] and [[kernel]].
