# systest - self-test
`systest` runs 74 checks and prints [ ok ] or [FAIL] for each:
  syscalls through `syscall` and `int 0x80`, bad addresses rejected,
  brk and mmap memory, the stack growing on demand, files in /tmp,
  chdir/getcwd, getdents64, fork/execve/wait, crashing children,
  two busy processes sharing the CPU (preemption + FPU state),
  nanosleep, kill, and rozlibc: printf, strtol, qsort, malloc,
  realloc, setenv, fopen/fgets, and networking: a TCP server and
  client over 127.0.0.1 and a UDP datagram ([[network]]), and
  random numbers ([[random]]), sscanf with doubles and SHA-256,
  and the scanf family (%[...], %n, fscanf), and (phase 13) pipes,
  poll(), shm_open and MAP_SHARED memory between processes, and (phase
  14) PTYs, AF_UNIX sockets, process groups and SIG_IGN.
  14b) Code and Files installed, rozui shortcuts and clipboard, icons
      folder, tcc compiling a rozui program.
The exit code is the number of failures (0 = all good).
Source: userland/tests/systest.c. See [[processes]], [[syscalls]].
