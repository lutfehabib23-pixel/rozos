# stty - console size
  `stty`           show rows and columns
  `stty 30 120`    set rows and columns
  `stty auto`      back to the screen size (142x50 on the framebuffer)
Full-screen programs ([[edit]], [[help]]) ask the kernel for this size
(ioctl TIOCGWINSZ). When you use the serial terminal on the PC its size
is different: find it there with `stty size` and set it here.
