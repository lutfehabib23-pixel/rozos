# Self-hosting
The goal: improve rozOS from inside rozOS.

== Step 1 (done): TCC rebuilds TCC ==
     `rozsh /usr/src/tcc/build-in-rozos.sh`
compiles /usr/src/tcc/tcc.c with /bin/tcc into /tmp/tcc-new. Test it:
     `/tmp/tcc-new /src/hello.c -o /tmp/h ; /tmp/h`
and install it with `cp /tmp/tcc-new /bin/tcc` if you want.

== Step 2: rebuild userland programs ==
Their sources are not on the disk yet; they will be put in /usr/src.

== Step 3 (done, phase 11): rebuild the kernel ==
  `cd /usr/src/rozos && make`
builds the whole kernel with [[make]] and [[tcc]]; then `make run-self`
on the PC boots it. Everything is explained in [[kernel-build]].

== Step 4 (done, phase 11b): install and boot it ==
`kinstall` then `reboot`: the new kernel is on the FAT boot partition
and in the boot menu, older ones stay as a fallback ([[kinstall]]).

== Step 5 (phase 17a): GNU tools ==
`rozpkg install binutils` gives GNU as, ld, ar, objdump ... inside rozOS
([[binutils]]). On the PC, GCC and G++ now target rozOS directly
([[toolchain]]).

== Step 6 (phase 17b): GCC inside rozOS ==
`rozpkg install binutils gcc`, then `gcc` and `g++` work in rozOS
([[gcc]]).
