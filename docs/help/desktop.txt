# The desktop (phase 14)
rozOS starts in the desktop (use `make run` to see the QEMU window):
  top panel     rozOS, the name of the front window, date and time
  icons         Terminal, Files, Code, Calculator, Paint, Images, Help -
                double-click (pictures: [[icons]])
  taskbar       Start; three pinned icons - Terminal, Files, Code (click =
                start it, or bring it to the front / minimise; a line under
                it = running; right-click = one more window); then an icon
                for every other window (click = front, again = minimise).
                Rest the mouse on an icon to see its name. Right side:
                network (bright = connected; click = Settings > Network)
                and sound (no sound driver yet) - phase 21. Phase 24a: the
                network sign is a LAN port - white = connected (has an IP),
                yellow = cable in but no address yet (DHCP), red with x =
                no cable / no link, grey with x = no network card
  Start menu    the programs of /usr/share/apps by category, then
                Terminal, About rozOS, Text mode, Restart, Shut down
  About rozOS   version, build number, CPU, memory, disk; Copy puts it all
                on the clipboard (Start > About rozOS, or right-click the
                desktop, or Settings > System)
Text programs from the menu open in a [[rozterm|terminal window]],
graphics programs in their own window ([[graphics]]).

== Right-click and your own icons (phase 19f) ==
Right-click the empty desktop:
  New text file        makes /home/Desktop/New text file.txt and opens it in Code
  New folder           makes /home/Desktop/New folder
  Add icon...          [[settings]] - put a program from the Start menu, or
                       your own command, on the desktop
  Change wallpaper...  [[settings]] - pick the background picture
  Settings...          [[settings]] (memory, processes, disks, network ...)
  Show hidden icons    also show what was hidden (dimmed) - phase 19g
  Refresh
Everything in /home/Desktop shows as an icon after the seven fixed ones:
.app files are program shortcuts (name:, run:, icon:, window: yes),
folders open in Files, pictures in Images, other files in Code.
Right-click your own icon: Open, Remove from desktop (shortcuts) or Show
in Files. The seven fixed icons always stay.
Phase 19g: folders also have Lock..., locked folders (padlock) Unlock...,
and every own icon Hide / Unhide - see [[rozlock]].
Phase 24a: files and folders also have Delete... - it asks "Are you
sure...?" and deletes only after Yes (a folder with everything in it).
A locked folder cannot be deleted: Unlock it first. (The helper is
`deldlg PATH`; Files has the same Delete on its toolbar.)

== Windows ==
Drag the title bar to move, drag the bottom-right corner to resize,
double-click the title for full size. [_] minimises (the taskbar
button brings it back), [□] full size / back, [X] closes - a program
that does not close in 3 seconds is stopped.

== Text mode and back ==
  `textmode`       (in a terminal) close the desktop, text console
  Start > Text mode   the same
  `desktop`        (in the text console) start the desktop again
  `textmode -r` / `textmode -p`   restart / switch off
Boot menu entry "rozOS factory (text mode, no desktop)" starts without
it once; for always: `mode=text` in /etc/rozos.conf ([[boot-menu]]).

== /etc/rozos.conf ==
  mode=desktop        or text
  utc_offset=+06:00   the clock's time zone (Dhaka); +00:00 = UTC
  wallpaper=          a picture: /usr/share/images/x.jpg (.jpg .png .bmp)
  wallpaper_style=    stretch (fill the screen, default) or fill (keep the
                      shape, the edges may be cut) - phase 19f; the desktop
                      notices changes to this file within a second
  splash=             picture shown while the desktop starts (phase 19b;
                      default /usr/share/images/rozos-boot.jpg, empty = none)
  splash_fade_ms=2500 it fades in from a black screen over this time (0 = at once)
  splash_ms=0         it stays at least this long from the start (0 = the
                      desktop comes as soon as the fade ends)

== The serial line ==
While the desktop runs, the keyboard belongs to it; the serial line
(`make run-serial`, or the terminal next to the QEMU window) gets its
own shell. [[kmon]] needs the text console - not a terminal window.
Colours (phase 14b): Ebony title bars, Obsidian desktop, Black panels,
Onyx / Dark Charcoal / Jet Black faces, White text, Grey lines.
The terminal cursor is a blinking white block.
More: [[rozwm]], [[rozterm]], [[signals]], [[rozui]], [[code]], [[filemanager]].
