# paint - draw with the mouse
  `paint`            new picture (the first save asks for a name)
  `paint pic.bmp`    open a picture and draw on it
Left button draws, right button erases. Top bar: colours, brush size
[ ] (or the wheel), fill (bucket), clear, save. Keys: 1-9 colour,
[ ] brush, f fill, c clear, s save, S save as, o open a picture
(.bmp .png .jpg ...), q quit. Saving asks for the folder and name the
first time (a file dialog), always writes BMP and says if it worked.
Look at the result with
[[imgview]]. Source: /usr/src/gfx/paint.c. See [[graphics]].
