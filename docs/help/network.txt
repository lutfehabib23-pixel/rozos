# Networking
rozOS talks TCP/IP through an Intel e1000/e1000e network card.

== The layers ==
  card driver   kernel/drivers/net/e1000.c - sends and receives frames
  lwIP          a small TCP/IP stack inside the kernel: ARP, IPv4,
                ICMP (ping), UDP, TCP, DHCP, DNS
  sockets       kernel/net/socket.c - turns lwIP into file descriptors
  rozlibc       socket(), connect(), send() ... ([[sockets]])
  programs      [[ifconfig]], [[ping]], [[nslookup]], [[http-get]]
A kernel thread "netd" checks the card every millisecond and runs
lwIP's timers (see it with `kmon` then `ps`).

== Addresses ==
At boot DHCP asks for an address. In QEMU's user-mode network:
  10.0.2.15   rozOS               10.0.2.2   your PC (and gateway)
  10.0.2.3    DNS server          127.0.0.1  rozOS itself (loopback)
The DNS server is written to /etc/resolv.conf; fixed names are in
/etc/hosts ("host" = 10.0.2.2). See [[qemu]] for the host side.

== Try ==
  `ifconfig`                 address and counters
  `ping -c 3 10.0.2.2`       is the PC answering?
  `ping google.com`          name lookup + internet
  `http-get http://example.com/`   fetch a web page
HTTPS (TLS) is phase 10; there is no firewall and no IPv6 yet.
